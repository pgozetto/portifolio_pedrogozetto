## Tecnologias

- Next.js 16 com App Router.
- React 19 e TypeScript.
- Tailwind CSS 4 e CSS personalizado.
- Lucide React para os ícones.
- Exportação estática otimizada para hospedagem.

## Como executar localmente

Requisitos: Node.js 22.13 ou superior e npm.

```bash
npm install
npm run dev
```

Depois, acesse `http://localhost:3000`.

## Gerar a versão de produção

```bash
npm run build
```

O Next.js gera a versão estática na pasta `out`.

## Estrutura principal

```text
app/
  globals.css              Estilos globais e responsivos
  icon.svg                 Favicon da marca
  layout.tsx               Metadados e layout principal
  page.tsx                 Página inicial do portfólio
  projetos/[slug]/page.tsx Páginas individuais dos projetos
components/
  site-motion.tsx          Animações e efeitos de movimento
public/
  pedro-hero-v2.webp       Imagem otimizada do Pedro
```
